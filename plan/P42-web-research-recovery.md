用户授权沿直接读网页 → 交付恢复 → 动态浏览器 → 沙箱代码执行的顺序推进。本包交付前两项，动态浏览器和代码沙箱仍待独立实施与验收。

第一层实现：公共 HTTPS 页面读取、页内查找/分页、沿已发现链接核验同一候选；保留来源与任务边界、读取次数和截止时间。GP 查询允许显式指定诊所域名。交付收到校验错误后提前自然结束，可在原有截止时间和失败次数内补一次修正；不重投 JEV 拒绝。

跨包契约：`websearch.PageReader` 提供读取结果；`agent.AgentDeps.pageReader` 为可选能力，由 worker 装配。`shared.PAGE_DNS_MODE` 默认为 system；本机 VPN 返回保留地址时可显式选择固定 HTTPS DNS，所有实际页面地址仍经公网校验并绑定到 TLS 连接。没有数据库迁移、对外发送新路径或模型供应商变化。

后续浏览器与代码执行须独立能力、按需装配：浏览器按任务隔离状态，代码在无网络/无宿主凭据的受限运行环境中执行；不能把宿主 shell 直接暴露为 Agent 工具。本机未配置 Docker 运行时；虽然安装了 Chrome，但尚未完成受控浏览器网络与任务隔离装配，不以宿主浏览器或 shell 冒充可用的隔离工具。
